# Fontes em PDF

Adicione aqui qualquer arquivo PDF: livros, documentação técnica, suas anotações, manuais, relatórios ou artigos. Subpastas são permitidas. O projeto extrai texto sem modificar os PDFs. Depois de adicionar arquivos, execute `prepare`.

PDFs fora de `PDFs/` não são fontes cadastradas. Resumos e fichas derivados devem ficar em `Conhecimento/10-Fontes/` ou `Conhecimento/20-Notas/` e citar páginas físicas.

Veja o [roteiro da biblioteca](../README.md) e o [guia de uso](../docs/usage.md).
