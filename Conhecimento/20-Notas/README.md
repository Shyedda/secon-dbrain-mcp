# 20-Notas

Esta pasta recebe resumos do fluxo de enriquecimento e conceitos derivados das fontes. Suas anotações originais entram em `Markdown/`; você não precisa organizá-las manualmente nesta pasta. Na curadoria avançada, mantenha um assunto principal por nota e cite a fonte com página física, seção ou linhas.

Os resumos enviados pelo MCP ficam aqui e começam como rascunhos `needs-review`. Não apresente conteúdo como fonte verificada antes de conferir a evidência original.

Veja o [roteiro da biblioteca](../../README.md) e o [guia de uso](../../docs/usage.md).
