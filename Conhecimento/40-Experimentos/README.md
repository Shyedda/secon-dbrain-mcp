# 40-Experimentos

Categoria para sínteses de experimentos e writeups já documentados nas fontes, quando houver curadoria avançada. O projeto não executa experimentos nem preenche automaticamente esta categoria. Seus registros originais entram em `PDFs/` ou `Markdown/`.

Não invente execução, resultados, métricas ou ambiente. Propostas ainda não realizadas devem ser identificadas como propostas.

Veja o [roteiro da biblioteca](../../README.md) e o [guia de uso](../../docs/usage.md).
