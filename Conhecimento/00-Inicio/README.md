# 00-Inicio

Esta pasta recebe o mapa geral e os agrupamentos por tema gerados por `prepare`. Eles orientam a recuperação das fontes e podem ser abertos em um editor Markdown ou no Obsidian opcional.

Mapas são pistas de navegação, sem garantia de relações conceituais ou cobertura integral. Você não precisa adicionar documentos aqui: use as duas pastas de entrada.

Veja o [roteiro da biblioteca](../../README.md) e o [guia de uso](../../docs/usage.md).
