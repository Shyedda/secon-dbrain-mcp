# Fichas de livros

Guarde aqui fichas em Markdown (`.md`) com título, autoria, edição, assuntos e páginas consultadas.
Coloque o PDF original em `Livros/`, na raiz do projeto; uma ficha não substitui o conteúdo do livro.
As fichas são indexadas, permitindo localizar referências junto com suas notas e os PDFs.
Use o template `source` de `90-Templates/` quando quiser padronizar a ficha.
Este README é apenas orientação e não entra na busca.
Veja o [roteiro da biblioteca](../../README.md).
