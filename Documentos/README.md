# Documentos

Use somente para manuais, documentação técnica e relatórios em PDF (`.pdf`).
PDFs em `Livros/` e `Documentos/` são indexados; PDFs em outras pastas não entram no índice.
Preserve a extensão e a autoria da fonte original.
Use Markdown nas demais pastas de conhecimento.
Veja o [roteiro da biblioteca](../README.md).
