# Sistema

Esta pasta contém o código, a configuração e as instruções de integração do SecOn Dbrain. Ela não é uma pasta de fontes e seus arquivos não devem ser adicionados ao acervo de conhecimento.

`config.json` define as pastas de entrada de PDF e Markdown (`input_dirs`) e o destino do conhecimento derivado (`knowledge_dir`). Preserve a configuração local de uma biblioteca existente e os originais em suas pastas configuradas. Consulte o [guia de uso](../docs/usage.md) para instalação, preparação e integração MCP.
